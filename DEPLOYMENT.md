# Deployment Guide: Morning Mobility (Foldable) to Hetzner VPS

This guide walks you through setting up and deploying the Morning Mobility (Foldable) PWA on your Hetzner VPS under the domain `foldable.onfc.xyz`.

---

## 1. Prerequisites on the Hetzner VPS
Before starting, ensure your Hetzner VPS has the following installed:
1. **Node.js** (v18 or v20+) & **pnpm**:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   sudo npm install -g pnpm pm2
   ```
2. **Nginx**:
   ```bash
   sudo apt-get update
   sudo apt-get install -y nginx certbot python3-certbot-nginx
   ```

---

## 2. VPS Folder Structure & Repository Cloning
We recommend placing the application under `/var/www/foldable`:

1. Create the application parent folder and set permissions (replacing `$USER` with your VPS SSH username):
   ```bash
   sudo mkdir -p /var/www/foldable
   sudo chown -R $USER:$USER /var/www/foldable
   ```
2. Clone the repository into `/var/www/foldable/app` directly:
   ```bash
   git clone <your-git-repository-url> /var/www/foldable/app
   ```

---

## 3. Build & Run Application on VPS
1. Navigate to the cloned folder:
   ```bash
   cd /var/www/foldable/app
   ```
2. Install dependencies using pnpm:
   ```bash
   pnpm install
   ```
3. Compile production assets:
   ```bash
   pnpm run build
   ```
4. Start the application daemon using PM2:
   ```bash
   pm2 start ecosystem.config.cjs
   ```
5. Ensure PM2 daemon restarts automatically if the VPS reboots:
   ```bash
   pm2 startup
   # Run the command generated by the output of pm2 startup
   pm2 save
   ```

---

## 4. Nginx Reverse Proxy Configuration
To make the application available on the internet under `foldable.onfc.xyz`:

1. Copy the Nginx blueprint (`scripts/nginx.conf`) to `/etc/nginx/sites-available/foldable.onfc.xyz` on your VPS.
2. Enable the configuration by symlinking it to `sites-enabled`:
   ```bash
   sudo ln -s /etc/nginx/sites-available/foldable.onfc.xyz /etc/nginx/sites-enabled/
   ```
3. Validate Nginx configuration integrity:
   ```bash
   sudo nginx -t
   ```
4. Reload Nginx to activate:
   ```bash
   sudo systemctl reload nginx
   ```

---

## 5. SSL/TLS Certificate Setup (HTTPS)
Use Certbot to secure your site with a free Let's Encrypt certificate:

1. Run Certbot for your domain:
   ```bash
   sudo certbot --nginx -d foldable.onfc.xyz
   ```
2. Follow the interactive prompts to generate the certificate and automatically redirect all HTTP traffic to HTTPS.
3. Test automatic certificate renewal:
   ```bash
   sudo certbot renew --dry-run
   ```

---

## 6. PM2 Management Commands
- Check process status: `pm2 status`
- View real-time logs: `pm2 logs foldable`
- Restart application gracefully: `pm2 reload foldable`
- Stop application: `pm2 stop foldable`
